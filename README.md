# BD Cricket Scorer

Flutter cricket tournament and live-scoring application.

## First development foundation
- Dark green and black dashboard
- Bangla / English toggle
- Player, team, and tournament name records
- Local persistence using SharedPreferences
- No Google login required
- No player photo upload

## Android build
GitHub Actions generates the Android platform files, runs Flutter analysis, builds a release APK, and uploads it as an artifact.

## Data storage
This first edition stores records locally on each device. Cross-device synchronization and shared online tournaments are not included yet.
